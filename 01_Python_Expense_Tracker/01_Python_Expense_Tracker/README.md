# Python Expense Tracker

A small command-line expense tracker that saves expenses to a local CSV file.

## Requirements
- Python 3.9+
- No external packages

## Run
```bash
python expense_tracker.py
```

Choose `1` to add an expense, `2` to view expenses, `3` to see totals by category, or `4` to exit. Data is saved in `expenses.csv` beside the script.
